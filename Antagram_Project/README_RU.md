# Antagram — комплект исходников (этап 1)

В репозитории находится SwiftUI-прототип Antagram. Это не готовый клон Telegram: исходники Telegram не объединены с приложением.

## Что есть
- Пять локальных тестовых аккаунтов.
- Начальные тестовые балансы 1000 Stars и 10 GRAM.
- Профиль, подарки и локальная админ-панель.

Все значения демонстрационные. Данные хранятся в UserDefaults и не синхронизируются между устройствами.

## Открытие
На Mac с Xcode открой `Antagram-Prototype/Antagram/Antagram.xcodeproj`.

## Безопасность
Не добавляй Supabase service_role/secret key, пароли базы данных или приватные ключи в клиентское приложение. Админские операции должны проверяться сервером.
