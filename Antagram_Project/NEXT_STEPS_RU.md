# Antagram — план следующей разработки

## Уже присутствует
- SwiftUI-приложение Antagram.
- Пять локальных тестовых аккаунтов.
- Демо-балансы 1000 Stars и 10 GRAM.
- Профиль, список подарков и локальная админ-панель.

## Ещё не реализовано
- Интеграция Telegram iOS UI.
- Чаты, диалоги, контакты, поиск, группы и каналы.
- Серверная регистрация, Supabase Auth, RLS и синхронизация.
- Серверная админ-панель и реальные операции с активами.
- Проверенная подпись IPA.

## Следующие этапы
1. Получить исходники Telegram iOS вместе с git submodules и проверить лицензионные требования.
2. Создать и настроить отдельный Antagram target, Bundle ID и брендинг.
3. Адаптировать необходимые UI-компоненты.
4. Подключить серверную авторизацию, таблицы, RLS и серверные операции.
5. Реализовать безопасное одноразовое начисление стартовых демо/внутренних балансов.
6. Собрать и протестировать приложение в Xcode.

## Ограничения
Для сборки требуется macOS/Xcode. GitHub Actions workflow в корне репозитория собирает неподписанный IPA на macOS runner. Сам ZIP исходников Telegram не интегрирован и не является готовым приложением Antagram.
