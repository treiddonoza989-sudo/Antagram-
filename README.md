# Antagram — этап 1

SwiftUI-прототип приложения Antagram и workflow для сборки неподписанного IPA через GitHub Actions.

## Состояние проекта

Это ранний демонстрационный прототип, а не готовый клон Telegram. Сейчас реализованы локальный вход по пяти тестовым аккаунтам, профиль, демонстрационные балансы Stars/GRAM и локальная админ-панель. Все данные хранятся на устройстве в UserDefaults; серверной синхронизации и реальных переводов нет.

## Тестовый вход

- Администратор: `+12281488` / `1488`
- `+12281489` / `1489`
- `+12281490` / `1490`
- `+12281491` / `1491`
- `+12281492` / `1492`

Каждому тестовому аккаунту выдаётся 1000 демонстрационных Stars и 10 демонстрационных GRAM.

## Сборка IPA

Открой вкладку **Actions** в GitHub и запусти workflow **Build unsigned Antagram IPA** через **Run workflow**. После завершения скачай artifact `Antagram-unsigned-IPA`. Внутри будет `Antagram-unsigned.ipa`. Он не подписан — перед установкой на iPhone его нужно подписать.

Workflow также запускается автоматически при push в `main`.

## Открытие в Xcode

Открой `Antagram_Project/Antagram-Prototype/Antagram/Antagram.xcodeproj`.

## Важно

Архив исходников Telegram (около 172 МБ) не помещён в этот репозиторий: GitHub ограничивает размер одного файла 100 МБ, и этот архив не интегрирован в приложение. Он остаётся в исходном ZIP-комплекте. Для полноценной интеграции потребуется отдельная работа с исходным репозиторием и его зависимостями/submodules.
